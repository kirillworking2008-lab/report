# Стержень 🔥

Личное Android-приложение для отчётов по задачам дня и недели и для
стержня жизни — принципов, на которых всё строится.

## Что внутри

- **Сегодня** — задачи на день (добавить, выполнить, удалить) и отметки
  принципов на сегодня с прогрессом дня.
- **Неделя** — сетка 7 дней (пн–вс): выполненные задачи и отметки стержня
  по каждому дню, задачи на любой день недели, сводка недели.
- **Стержень** — круговая **3D-карусель** из 7 принципов: карточки стоят
  по кругу, разворачиваются в объёме, крутятся свайпом и сами медленно
  вращаются. Карточка спереди показывает детали и историю за 14 дней.
- **Отчёты** — статистика: метрики, график задач за 7 дней, **карта дней
  за 12 недель** (зелёный — чистый день, красный — срыв, серый — не отслеживалось),
  стрик и история по каждому принципу.

## Стержень жизни

Каждый принцип — пассивная задача, поэтому отмечать каждый день ничего
не нужно: **день засчитывается автоматически**, а **стрик-огонёк 🔥
обновляется сам** (проверка смены суток каждые 20 секунд).

- Держишься — огонёк просто растёт: +1 каждый день.
- Сорвался — нажимаешь «Отметить срыв сегодня»: серия обнуляется,
  в истории дня остаётся красная точка. Срыв можно отменить.
- Рекорд (лучшая серия) сохраняется отдельно.
- **Дату начала отсчёта можно менять вручную** для каждого принципа:
  на экране «Стержень» или в шторке принципа на «Сегодня» → «Начало отсчёта» →
  выбираешь день в календаре. Если держишься давно и ставишь приложению
  стартовую дату задним числом — огонёк сразу покажет честную серию.
  Будущие даты выбрать нельзя, есть кнопка «Начать с сегодня».

## Дизайн

Тёмная «стеклянная» эстетика:
- глубокий фон `#07070B` с медленно дрейфующими цветными пятнами (aurora);
- стеклянные карточки с подсветкой сверху и тонкой градиентной рамкой;
- кольца прогресса вокруг иконок принципов (заполняются за 30 дней);
- живые огоньки с пульсирующим свечением, цвет меняется по длине серии;
- крупные цифры с градиентной заливкой и плавным счётом;
- плавающая нижняя навигация с анимированной подсветкой активного раздела;
- нижний лист (bottom sheet) для отметки срыва;
- прогресс до следующей вехи (неделя → месяц → 100 дней → год);
- карта дней в стиле GitHub-контрибьюшенов;
- анимированные переходы между разделами (fade + подъём).

Превью дизайна (интерактивный макет на CSS 3D, не само приложение) лежит в
`preview/index.html` — открой в браузере: можно крутить карусель мышью,
переключать экраны и вызывать шторку срыва.

## 3D-карусель

Карточки расставлены по цилиндру: для каждой — `rotateY(угол) translateZ(радиус)`,
поворот всего кольца задаёт `angle`. В Compose то же самое сделано через
`graphicsLayer { rotationY = a; cameraDistance = 16f * density; scaleX/scaleY = перспектива }`,
плюс `zIndex` по косинусу угла, затухание к задней стенке и мягкое свечение
под передней карточкой. Карусель:
- крутится свайпом с инерцией и доводкой до ближайшей карточки (spring);
- сама медленно вращается, пока её не тронули;
- по тапу на карточку выносит её вперёд;
- снизу — индикатор позиции, под каруселью — детали активного принципа.

## Технологии

- Kotlin + Jetpack Compose (Material 3)

- Данные хранятся только на устройстве

## Сборка APK

APK собирается автоматически в GitHub Actions при каждом пуше:
**Actions → Build APK → sterzhen-apk** (артефакт с APK).

Локальная сборка (нужны JDK 17 и Android SDK):

```bash
gradle wrapper --gradle-version 8.7   # один раз, если нет gradlew
./gradlew assembleDebug               # отладочный APK
./gradlew assembleRelease             # релизный APK (подписан debug-ключом)
```

APK лежит в `app/build/outputs/apk/debug/` или `.../release/`.
Установи его на телефон (разреши установку из неизвестных источников).
