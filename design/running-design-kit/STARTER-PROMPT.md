# Промпт для новой сессии

Скопируйте текст ниже в новый чат Arena и приложите архив **`Running-Design-Kit.zip`**
(или просто загрузите `theme.css`). Замените `<ИДЕЯ ПРИЛОЖЕНИЯ>` на своё описание.

## 📋 Текст промпта

```
Хочу новое приложение с дизайном как у Running (тёмный «стеклянный» интерфейс).
В архиве Running-Design-Kit.zip лежит готовая дизайн-система: theme.css,
демо-страница index.html (там видны все компоненты) и эта инструкция.

ИДЕЯ ПРИЛОЖЕНИЯ: <ИДЕЯ ПРИЛОЖЕНИЯ>

КОНТЕКСТ ДИЗАЙНА
- Это мобильное веб-приложение (PWA), открывается в WebView на Android.
- Тёмный фон #080d12 → каркас .app-shell с градиентом и мягким свечением.
- Стеклянные карточки .card / .stat-card, акцент #73e3cf (mint),
  альтернативы: data-theme="violet" / "amber" — вся палитра в theme.css.
- Шрифт Inter / system-ui, плотные отрицательные трекинги в заголовках,
  tabular-nums для цифр.
- Максимальная ширина 440px, safe-area-inset, нижнее меню на blur-подложке.
- Все иконки — inline SVG, stroke 1.7–2.2, без сторонних иконочных шрифтов.

ТРЕБОВАНИЯ
1. Использовать theme.css как есть: не переписывать токены и не вводить
   новые цвета — только var(--accent), var(--ink), var(--muted) и т.д.
   Если нужен новый компонент, собрать его из существующих токенов.
2. Стек: чистый HTML + CSS + JS, без сборки и без фреймворков.
   Supabase (если нужна синхронизация) — только через vendor/supabase.min.js.
3. Состояние хранить в localStorage, экраны переключать без перезагрузки.
4. Мобильный первый: 360px — целевая ширина, никакого горизонтального скролла.
5. Доступность: aria-label у иконочных кнопок, aria-current у активного
   пункта меню, focus-visible уже настроен в теме.
6. Компоненты, которые уже есть и которые нужно переиспользовать:
   .app-header/.brand, .card/.card-hero, .stat-grid/.stat-card,
   .bar-track/.bar-fill, .day-bars, .list/.list-row, .segmented, .chip,
   .input/.field, .primary-button, .ghost-button, .bottom-nav, .toast,
   .sheet + .sheet-backdrop, .app-menu, .empty.
7. Структура проекта:
   index.html, styles.css (только дополнения к теме), app.js, theme.css,
   icons/ (иконки приложения), service-worker.js + manifest.webmanifest.

ЧЕГО НЕ ДЕЛАТЬ
- Не менять Supabase/Auth/схему БД, если они не нужны этой идее.
- Не подключать CDN, шрифты с внешних серверов, аналитику.
- Не добавлять светлую тему и «материальный» дизайн — стиль строго тёмный.

ПЕРВЫЙ ШАГ
Собери каркас: index.html с .app-shell, шапкой, нижним меню на 3–4 пункта
и одним рабочим экраном. Покажи предпросмотр, потом наращивай функции.
```

## 🎯 Быстрые правила стиля (шпаргалка)

- **Фон:** `#080d12` + радиальный градиент сверху; каркас `.app-shell` не шире 440px.
- **Стекло:** `linear-gradient(145deg, rgba(255,255,255,.055), rgba(255,255,255,.022))`
  + бордер `rgba(255,255,255,.085)` + внутренняя светлая линия сверху.
- **Акцент:** только один на экран, через `var(--accent)`. Свечение —
  `box-shadow: 0 0 12px rgba(var(--accent-rgb), .3)`, не больше.
- **Радиусы:** карточки 17px, поля 14px, кнопки 16px, шторка 26px, меню 30px.
- **Типографика:** заголовок экрана 13px/660, метрика 20–38px/680 с `-0.045em`,
  подпись 9px/690 uppercase с `0.09em`, текст 11–12px/1.5.
- **Отступы:** контент 18px по бокам, между секциями 20–21px.
- **Анимации:** 160–260 мс, `cubic-bezier(.2,.8,.2,1)`; уважать
  `prefers-reduced-motion` (уже в теме).
